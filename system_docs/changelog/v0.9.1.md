## Tính năng mới

- **Auto-refresh realtime**: Hook `useAutoRefresh` polling dữ liệu mỗi 8s, tự động dừng khi tab ẩn, resume khi tab hiện.
- **Nút "Làm mới" thủ công** trên header của Manager Portal, Sale Portal, KOL Manager Portal.
- **Tự động đồng bộ** khi có user khác thay đổi data (duyệt đơn, phân bổ KOL, upsale...).
- **Hệ thống thông báo realtime**:
  - **Bell icon + dropdown** ở header dashboard, hiển thị số thông báo chưa đọc.
  - **Toast push notification** hiện ngay khi có thông báo mới (khi đăng nhập lần đầu hoặc tab đang mở).
  - **10 loại thông báo** tích hợp vào workflow:
    - 🔔 **Sale**: được chỉ định đơn mới, claim được duyệt/từ chối, KOL được phân bổ.
    - 🔔 **Manager/Admin**: có đơn mới từ Landing Page, Sale claim đơn, KOL submit profile duyệt.
    - 🔔 **KOL Manager**: có đơn cần phân bổ KOL, hồ sơ KOL cần duyệt.
    - 🔔 **KOL**: được phân vào đơn hàng mới, hồ sơ được duyệt/từ chối.
  - **Đánh dấu đã đọc** từng cái hoặc tất cả.
  - **Tóm tắt thông báo**: tổng số, chưa đọc, cần hành động.
- **Changelog động**: Đọc từ file `.md` trong `system_docs/changelog/`, tự động sort theo version.
- **Quy chuẩn changelog**: File `RULES.md` hướng dẫn chi tiết cách tạo file version mới.
- **Template changelog**: `_TEMPLATE.md` để copy nhanh khi tạo phiên bản mới.

## Cải tiến

- **Upsale đơn hàng**: lưu lịch sử thay đổi, so sánh TRƯỚC/SAU trực quan.
- **Manager Portal** thêm cột "Minh chứng" để tải proof file/link.
- **Bảng KOL Manager** gọn gàng: tách Nền tảng, Số bài ra cột riêng.
- **Database migration**: column type `total_amount` / `deposit_amount` → BigInteger để tránh lỗi overflow.

## Fix bug

- Fix lỗi `integer out of range` khi nhập giá trị hợp đồng > 2 tỷ.
- Fix `assign-kol 422` → backend schema nhận `kol_ids` (array) thay vì `kol_id` (single UUID).
- Fix error handling trong `AssignKolModal` → không crash khi API trả về validation error.
- Fix `kol_booking_price` không được lưu → thêm field vào schema `KOLOnboardingRequest`.
- Fix landing page không hiện KOL → thêm hướng dẫn set `is_public=true`.
- Fix `react-markdown` dependency → thêm vào `package.json` và regenerate lock file.
- Fix SQLAlchemy `metadata` reserved keyword → đổi thành `extra_data`.
- Fix KOL profile submit không reset về pending → thêm logic đúng.
- **Fix luồng workflow quan trọng**: Thêm trạng thái `pending_sale_info` → KOL Manager KHÔNG thể nhìn thấy đơn cho đến khi Sale cập nhật xong thông tin.
- Audit security: fix axios SSRF vulnerability qua `npm audit fix`.
